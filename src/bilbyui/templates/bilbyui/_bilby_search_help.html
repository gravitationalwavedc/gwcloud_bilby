{# In-place search help panel for bilby job surfaces (my/public jobs) (issue #51, task-3). #} {# Included by _search_form.html via search_help_template and toggled by the #} {# "(?)" button (data-target="#search-help"). Same structure/position as the #} {# GWFlow help panel (WCAG 3.2.6). #}

Searchable fields:

  • job.name — job name
  • job.description — job description
  • labels.name — label
  • eventId.eventId — event ID
  • eventId.triggerId — trigger ID
  • eventId.nickname — event nickname
  • params.* — job parameters
  • ini.* — INI file settings

Examples:

  • job.name:GW150914*
  • labels.name:o4a AND eventId.nickname:GW150914
