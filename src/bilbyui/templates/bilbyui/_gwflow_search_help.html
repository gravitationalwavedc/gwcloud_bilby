{# In-place search help panel for GWFlow surfaces (issue #51, task-3). #} {# Included by _search_form.html via search_help_template and toggled by the #} {# "(?)" button (data-target="#search-help"). Same position/label on every #} {# surface (WCAG 3.2.6). #}

Searchable fields:

  • sname — superevent name
  • libraries — workflow library
  • schemaVersion — schema version
  • analyses.uid — analysis UID (unique identifier)
  • analyses.software — software package
  • analyses.waveform — waveform model
  • analyses.analysts — analyst
  • analyses.reviewers — reviewer
  • analyses.runStatus — run status
  • analyses.reviewStatus — review status
  • gracedb.uids — GraceDB UID (Gravitational-Wave Candidate Event Database)
  • gracedb.instruments — instruments
  • eventId.triggerId — event trigger ID

Abbreviations:

  • UID — unique identifier
  • PE — parameter estimation (an analyses.* type)
  • TGR — tidal gravitational radiation analysis (an analyses.* type)
  • GraceDB — Gravitational-Wave Candidate Event Database
  • CBC — compact binary coalescence

Examples:

  • sname:S2306*
  • analyses.software:bilby AND analyses.waveform:IMRPhenomXPHM
  • libraries:cbc-workflow-o4c AND analyses.reviewStatus:reviewed
